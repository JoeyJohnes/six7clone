# Виральные ролики для Six7 через Hypit

[Hypit](https://github.com/hypit-ai/hypit) — open-source навык (Skill) для Claude Code и Codex, который
разбирает трендовый ролик (TikTok, Reels, Shorts) и превращает его в редактируемый шаблон, а потом
собирает по нему новое видео под нашу тему.

## Как это работает

1. **Разбор референса.** Агент смотрит ролик, вытаскивает кадры, читает речь с таймингом
   (WhisperX), фиксирует, на каких словах появляются титры, перебивки, B-roll, эффекты и звуки.
2. **Шаблон.** Структура записывается в файлы проекта:
   - `*.svml` — сценарий и композиция; события привязаны к **словам**, а не к секундам,
     поэтому при новом тексте тайминг сам перестраивается;
   - `*.svs` — визуальный стиль (look) и режиссура;
   - `*.svrun` — что генерировать и чем.
3. **Сборка.** Агент генерирует недостающий материал (картинки, видео, голос) или использует
   наш, а графику и титры рендерит кодом в headless Chromium. Результат открывается в Studio —
   там можно поправить таймлайн.

Для простых роликов **с титрами и моушн-графикой генеративные модели не нужны**: текст, плашки,
анимации и «кодовые» визуалы собираются локально, без платных API. Модели (HypiHub или свои ключи)
нужны только для аватаров, озвучки и сгенерированного видео/фото. Перед любыми платными вызовами
агент показывает смету и ждёт подтверждения. Примеры из репозитория с генерацией стоят ~$1–1.2 за ролик.

## Установка (один раз, глобально)

```bash
npx skills add hypit-ai/hypit -g
```

Ставится только навык. CLI `hypit` (`@hypit/hypit`, Node 22.15+) агент проверит и предложит
установить сам при первом запуске. Видеопроект лучше держать **отдельно** от этого Next.js-репо
(например, `~/six7-video/`), чтобы рендеры и `node_modules` Hypit не попадали в сборку сайта.

## Что взять из этого репо

| Материал | Путь | Зачем |
| --- | --- | --- |
| Логотип | `public/images/six7-logo.png` | Брендинг в финальном кадре / вотермарк |
| Кадры фонового видео | `public/bg-frames/` | Фон или B-roll в фирменной стилистике |
| OG-картинка | `public/og-image.jpg` | Обложка / превью |
| Оффер | `src/app/layout.tsx` (metadata) | «Делаю так, чтобы ваш бизнес работал без вас. Запуск за 3 дня.» |

## Готовые запросы

Клон трендового ролика под Six7:

```text
/hypit Возьми этот ролик как референс: <ссылка на TikTok/Shorts или путь к mp4>.
Разбери, почему он цепляет: хук, перебивки, титры, на каких словах что появляется.
Собери версию про Six7 — автоматизацию бизнеса «от записи до оплаты» с запуском за 3 дня.
Язык — русский, формат 9:16, в конце CTA «Напиши — запустим за 3 дня» и логотип
из ./assets/six7-logo.png. Сохрани структуру и ритм оригинала.
```

Без генеративных моделей (только титры и графика):

```text
/hypit Сделай 20-секундный ролик 9:16 без генеративных моделей — только кинетические титры,
моушн-графика и музыка. Тема: «5 задач, которые ИИ закрывает за владельца бизнеса»:
запись клиентов, напоминания, оплата, отчёты, ответы в мессенджерах.
Фирменные цвета: тёмный фон, акцент #2ca9e1, шрифт Roboto Mono. Финал — логотип Six7 и CTA.
```

Пачка вариантов из одного шаблона:

```text
/hypit По готовому шаблону сделай 5 вариантов с разными хуками в первые 2 секунды
(салоны красоты, стоматологии, фитнес-клубы, автосервисы, онлайн-школы). Остальное не меняй.
```

## Лицензия — на что обратить внимание

Hypit распространяется по модифицированной Apache 2.0. Использовать его для своих роликов, в том
числе коммерческих и для клиентов, можно. Нельзя без отдельной лицензии: поднимать на его основе
мультитенантный сервис/SaaS для третьих лиц и перепродавать сам Hypit или его производные.
